# Advanced CMOS Microfabrication — Interactive Digital Learning Module

**Course:** ECE112 / 213ECE2362 · Regulation 2025 · Professional Elective (3-1-0-0-4)
**Department:** Electronics and Communication Engineering
**Institution:** Kalasalingam Academy of Research and Education, Krishnankoil, Tamil Nadu
**Author:** Dr. Shashi Kant Dargar, Course Coordinator
**Published:** September 2026

## Open the module

**[Launch the interactive module](https://shashikantdargar-lgtm.github.io/advanced-cmos-microfabrication/)**

Runs in any modern browser. No plugin, server or installation. The single HTML
file also works offline once downloaded.

## What it contains

- Full syllabus, course outcomes and CO–PO/PSO mapping
- Interactive cross-section simulator for the eight-step replacement metal
  gate flow, with process, thermal budget and metrology readouts
- Sample micro-lesson 3.3, "Why the gate had to change"
- Video storyboard and narration script for an 11-minute micro-lecture
- Equivalent oxide thickness workbench (EOT = t × 3.9/k)
- Misconception check and self-assessment with diagnostic feedback
- Laboratory brief for SEMulator3D® Assignment 6 with a four-part rubric
- Eight innovative pedagogy strategies mapped to course outcomes
- Production plan for the remaining 29 micro-lessons

## Accessibility

Keyboard operable, screen-reader labelled, and readable without colour as the
sole channel. All diagrams are original schematics drawn for this course.
